## 复跑与证据

本次代码基于 01e2a8a，加上工作树内的限流修复。统一检查用 npm test，协议联测用 npm run test:mcp。macOS 跳板实窗复验和供应链检查命令见[安全复查](安全复查.md)。两种 MCP 传输指 HTTP 与 stdio。百次并发指 100 个同步起跑的实际 GET，包括服务限流和连接上限的拒绝路径。

实窗顺序为智能粘贴、草稿提交与确认、查找单条、主窗口批准、GET、重复兑换、等满 122 秒、拒绝、关闭公网和重新开放。回环跳板直连覆盖完整可视流程。端到端加密桥接及新设备接管使用真实网络连接和主设备状态层另测。智能粘贴、草稿核对及入库后的画面可在[截图目录](验收截图)查看。
