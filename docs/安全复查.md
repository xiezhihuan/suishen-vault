# 安全复查 · 2026-11-24

复查对象是本轮桌面包、共享核心、客户端桥接和本机测试跳板。使用假数据。PRD 每条标准的判定和运行输出在[验收清单](验收清单.md)。下表与[威胁模型](威胁模型.md)使用同一编号。

| 威胁 | 本轮如何检查、看到了什么 | 仍需注意 |
|---|---|---|
| T1 恶意 AI | 官方 SDK 列工具、提草稿、申请单字段；实窗重新验证后才交付。未批准的草稿搜不到。 | 用户交给 AI 的字段会进入对话。批准页缺少客户端自称信息。 |
| T2 与 AI 同机 | 锁定状态不能读条目或机密；核对主窗口能力、网络路由、桥接命令。 | 同一用户下的恶意进程仍可能读取输入和内存；未测系统钥匙串授权对话框。 |
| T3 令牌泄露 | 测试跨客户端读取、仅令牌取用和撤销；都未取得目标字段；生成配置无令牌。 | 显式设置 SUISHEN_BRIDGE_DIR 的文件模式会保存凭据。桌面接入使用默认钥匙串。 |
| T4 猜码及重复使用 | 实等 122 秒、错五次、错客户端、错绑定、100 个并发 GET；并发测试只交付一次，申请 ID 与码不匹配也拿不到字段。 | 屏幕上显示的码可被旁观，进入 AI 的码可进入对话历史。 |
| T5 跳板失陷 | 两端固定公钥，抓取本地转发字节，在桥接模式核对假标记；测试握手重放、接管及旧连接。另用实窗在回环跳板主动开启直连测授权。 | 直连会把令牌和获批明文暴露给代理；本轮未部署真实公网 HTTPS。 |
| T6 设备失窃 | KDF 越界、错误凭据、锁定和恢复密钥轮换测试通过。 | 未验证安卓生物识别、实际锁屏和休眠。 |
| T7 授权疲劳 | 测试单客户端待办上限、拒绝冷却；组件检查默认焦点、延时按钮和固定通知文案。 | 未由人观察系统通知，用户仍需核对字段。 |
| T8 枚举 | 测搜索最小长度、滚动配额、30 项暂停、五项上限、不可见项及不透明引用。修复限流等待时间传递，SDK 在两种传输均收到重试秒数。 | 多天低频查询仍可能推测元数据。 |
| T9 截屏与剪贴板 | 检查桌面内容保护与 Android 窗口标志，组件验证遮回与只清除同次复制。实窗截图只使用允许截图的独立调试库。 | 未在本轮实测各系统截图、剪贴板历史或云同步。 |
| T10 备份与迁移泄露 | 试错码、错主密码、篡改和非空目标，扫描包内容，验证老备份仍需要当时的凭据。 | 不会撤销用户已手工复制的备份。 |
| T11 恶意网页 | 错 Host 返回 421，带 Origin 返回 403，未见 CORS 允许头；预取不消耗码。 | 同机程序仍能探测开放端口。 |
| T12 局域网 | 查看设置入口和监听器，局域网按钮禁用。桥接配对实际验证公钥。 | 缺少局域网 TLS 监听，不能判定此项已实现。 |
| T13 日志与崩溃 | 扫描 DB、备份、迁移、实窗专属临时目录、stdout/stderr 和系统日志。测试专属目录额外检查实际生成的令牌、授权码及跳板配对码。 | 当前崩溃报告为零，未生成系统内存转储；通知横幅未授权。系统日志只用静态假标记检索。 |
| T14 旧设备与副本 | 两个 App 状态实例在独立目录迁移，旧端关闭；新设备用新配对码接管，旧设备即使取消迁移也重新上线失败。另测输入完成码停用、清除。 | 未在两种操作系统之间用实际窗口迁移。 |
| T15 供应链 | 核对锁文件、密码学依赖、许可证、包哈希。挂载最终 DMG 检查主程序和桥接的签名。 | macOS 无公证，Windows 未签名；哈希不能代替可信发布者签名。 |

录入助手另核对了威胁模型的五种情况。假网址用例检查完整 ASCII 域名和不允许的 URL 形式；草稿轰炸用例检查权限、配额与无读回入口；未知字段和疑似机密被拒；HTML 用 React 文本节点原样显示；粘贴分段用属性测试验证可还原，实窗确认密码前后空白没有丢失。合法外观的假网站与不具特征的秘密仍需本人辨认。[自动测试](验收证据/自动测试.txt) · [界面测试](验收证据/界面.txt) · [实窗记录](验收证据/跳板实窗.txt)

**磁盘与历史。** 核心测试有已知标记的阳性对照，扫描整个假密库生命周期。实窗还扫描测试目录内的文件、进程输出以及本机产品专属缓存。另在系统日志按进程过滤，不保存原始整机日志。在 Git 中逐提交检查文件名，对所有本地引用可达的文件内容和提交消息检查私钥头及常见服务商凭据特征，没有输出匹配值。模式扫描无法识别任意无特征的短字符串，也不覆盖远端、已回收对象或任意第三方软件的记录。[系统痕迹](验收证据/系统痕迹.txt) · [Git 历史](验收证据/Git历史.txt) · [可复跑脚本](../scripts/audit-history.py)

**依赖。** npm 官方审计返回总计 0 项已知漏洞。RustSec 在线更新超时，使用本机修订 52384ab5 的 1,563 条公告检查了 591 个锁文件依赖，报告 0 项漏洞和 6 项警告。chrono、proc-macro-error、zbus_names、zvariant、zvariant_derive 已停止维护；glib 的 VariantStrIter 有不健全实现警告。未将缓存结果当作最新线上结论。Rust 与 npm 许可证表达式未发现必须采用 GPL/AGPL 的依赖；双许可项可选择 MIT 或 Apache。MPL-2.0 的文件级义务、许可证文本与随包声明仍需在对外分发时逐项核对。核心使用 RustCrypto、getrandom、subtle 与 zeroize。本轮没有引入新密码学算法。[审计输出](验收证据/依赖审计.txt)

复验命令，在仓库根目录运行。实窗脚本使用独立数据目录，系统剪贴板和钥匙串无需授权。跳板模式只连接本机回环端口 47382，不连接用户服务器。
