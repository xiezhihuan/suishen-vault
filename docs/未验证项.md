## 本阶段没有实现

已在 macOS arm64 上验证核心和桌面壳编译，范围及依赖审计见 [密库核心](密库核心.md)。Windows 与 Android 的 SQLite 文件权限、崩溃恢复、迁移与性能仍待实机验证。现有测试以事务中断快照与强杀子进程模拟掉电，未在真实断电或故障存储介质上测试。

本机服务、主窗口批准和授权码兑换的验证记录见 [本机服务](本机服务.md)。macOS 主窗口的操作记录见 [桌面端](桌面端.md)。系统钥匙串授权提示、休眠唤醒和操作系统崩溃转储未验。测试使用临时密库和假数据。Windows/Android 未进行同等构建或实机验证。

局域网档没有实现，界面上不可选（端到端 TLS 与配对代码可以复用，缺监听与网卡选择）。公网跳板的验证记录见 [公网跳板](公网跳板.md)。重新打包的安装包没有生成，`dist` 里仍是上一版，不含公网功能。批准页没有显示「客户端自称信息」，因为服务目前不收集它。Android 的剪贴板写入会明确报错，等 Android 任务实现。

## 需要用户本人决定的步骤

| 事项 | 命令或步骤 | 没有代办的原因 |
|---|---|---|
| 部署到自己的服务器 | 按 [公网跳板](公网跳板.md) 的部署一或部署二 | 需要真实服务器、域名与登录 |
| 删除测试留下的空构建器 | 启动 OrbStack 后运行 `docker buildx rm sv-relay-test`，再 `docker image rm moby/buildkit:buildx-stable-1` | 本任务自己建的，但删除命令被自动权限检查拒绝，没有绕过 |
| 用 cargo-xwin 生成 MSVC 版 Windows 包 | `cargo install cargo-xwin`，再 `cd apps/client && npm run tauri -- build --runner cargo-xwin --target x86_64-pc-windows-msvc --bundles nsis` | 首次运行会下载微软 CRT 与 Windows SDK，等于接受微软许可条款。已改用 llvm-mingw 产出 gnullvm 版 |
| 在 Windows 上验证安装包 | 把 `~/.cache/suishen-vault/dist/SuishenVault_0.1.0_x64-setup.exe` 拷到 Windows 安装，按 [桌面端](桌面端.md) 的验证表走一遍 | 需要 Windows 设备 |
| 运行 Windows 工作流 | 推送仓库后在 GitHub Actions 手动运行 `windows` | 不推送远程 |
| 允许 macOS 通知 | 系统设置 → 通知 → SuishenVault | 系统授权由用户决定 |
| 打开没有公证的应用 | 系统设置 → 隐私与安全性 → 仍要打开 | 系统授权由用户决定 |
| macOS 签名与公证 | 加入 Apple 开发者计划后设置 `APPLE_SIGNING_IDENTITY` 等环境变量再运行 `npm run package` | 需要付费与登录 |

## 录入助手的验证范围

macOS arm64 已用真实 Tauri 窗口与独立官方 SDK 客户端走通录入、核对、授权、GET 取用和重放拒绝。使用回环测试页驱动实际 WebView 控件，未使用辅助功能模拟键鼠。系统对 `osascript` 报告辅助访问未获准，没有代为授权。可运行 `npm run client:dev`，用独立假密库手动按 [本机服务](本机服务.md#允许某个-ai-提交草稿) 重走流程。

Windows 和 Android 的新录入界面、系统剪贴板、输入法与真实屏幕锁定仍待对应设备验收。Windows 可在仓库根目录执行 `npm ci`、`npm test` 和 `npm run client:dev`。Android 须由用户决定是否安装 SDK/NDK 并接受许可，再执行 `cd apps/client && npm run tauri -- android init && npm run tauri -- android dev`。本阶段 Android 没有接入原生剪贴板清理。真实 Claude/Codex 账号与用户的公网服务器未用于本次验收。

本次没有改动用户系统剪贴板中的现有内容。比较原文与复制序号的逻辑已做自动测试，系统剪贴板写入及清空的交互测试可等剪贴板可覆盖时执行 `npm run test:desktop`。新增草稿已在本机服务与两种 MCP 传输验证，本次没有重建 Docker 部署或生成新安装包。容器环境复验命令为 `npm run test:relay` 和 `npm run test:deploy`。
